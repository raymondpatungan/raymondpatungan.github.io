04 / DEFECT MANAGEMENT

A good bug report saves time.

Clear reproduction steps, expected versus actual results, impact, and useful supporting information.

BUG-1042

Login button remains enabled with empty credentials

Medium
ENVIRONMENT

Chrome · macOS · QA Environment

PRECONDITION

Login page is accessible.

STEPS TO REPRODUCE
  1. Open the login page.
  2. Leave username and password empty.
  3. Observe the Login button.
EXPECTED

Login should remain disabled until required fields are completed.

ACTUAL

Login button remains enabled and allows submission.
