04 / DEFECT MANAGEMENT

Clear defects lead to
faster resolution.

A useful bug report gives developers enough information to reproduce, understand and resolve the problem.

BUG-0042

Login accepts invalid password

HIGH OPEN
ENVIRONMENT Chrome / macOS / Demo
TYPE Functional
PRIORITY High
STATUS Open
STEPS TO REPRODUCE
  1. Navigate to the login page.
  2. Enter a valid username.
  3. Enter an incorrect password.
  4. Select Login.
EXPECTED RESULT

The application should reject the credentials and display an appropriate error message.

ACTUAL RESULT

The application proceeds to the authenticated dashboard despite the incorrect password.

05 / TEST DESIGN

Test with intention,
not repetition.

TC-LOGIN-001 LOGIN MODULE

Verify successful login with valid credentials

PRECONDITION

A registered user account exists.

STEPS

1. Open login page.
2. Enter valid username.
3. Enter valid password.
4. Click Login.

EXPECTED RESULT

User is successfully authenticated and redirected to the dashboard.

06 / AUTOMATION

Automate what should
not be repeated manually.

Automation is most useful when it reduces repetitive work, improves regression coverage and provides fast feedback.

01
Identify repetition

Find stable scenarios that are executed frequently.

02
Automate strategically

Prioritize high-value regression and repeatable tests.

03
Keep humans in the loop

Exploratory testing and judgment still matter.

login_test.java SELENIUM 
WebDriver driver =
    new ChromeDriver();

driver.get("/login");

driver.findElement(
    By.id("username")
).sendKeys("testuser");

driver.findElement(
    By.id("password")
).sendKeys("password");

driver.findElement(
    By.id("login")
).click();

assertEquals(
    "Dashboard",
    driver.getTitle()
);
Automated functional test ✓ PASS
Important distinction: Test automation and business-process automation are different. My experience includes Selenium-based test automation as well as workflow automation using tools such as Power Automate, Excel VBA, Zapier and Make.
